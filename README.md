# Líder Visão — versão estática

Envie o conteúdo desta pasta à raiz do repositório GitHub.
Na Vercel, importe o repositório e selecione Framework Preset: Other.
Root Directory: raiz do repositório. Sem comando de build ou instalação.
Output Directory: ponto (.).

GTM instalado: GTM-NWMLCLNJ, com script padrão e noscript.
Os sete links de WhatsApp usam o endereço Tintim fornecido pelo cliente.
As mensagens e o número de destino são administrados no Tintim.

Validar no domínio final com Tag Assistant e com uma conversa de teste no Tintim.
As tags e acionadores precisam estar configurados e publicados dentro do GTM.
Depoimentos são exemplos ilustrativos, identificados na página; substituir antes da publicação.
Esta é uma restauração estática parcial; não inclui painel WordPress ou backend de formulários.
